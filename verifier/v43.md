   key discovery — **LANDSCAPING is CENTERED under TERRAVIAN** (line centers 638.5 vs

   0.885, gap ratio 0.271, center delta ~0, pixel IoU after scale-alignment):
   - TERRAVIAN tracking: reference uses natural Cinzel spacing → 0.04em was too wide;
     best fit -0.011em (T width 1072.2px vs reference 1072px).

     (L width 950.9px vs reference 949px).

     NEGATIVE → -1px at 22px (glyph gap ratio 0.265–0.29 vs target 0.271).
   - Centering: flex-col items-center → center delta 0.00–0.50px.
4. Only after the lab render matched did we apply the parameters to SiteHeader.tsx.
