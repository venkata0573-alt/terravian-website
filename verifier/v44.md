## Baseline (measured 2026-09-09, production runner, fresh contexts, 3.5s window)
- Loader: mark-circle.png 640px, 86KB, downloaded on EVERY page's initial load.
  Pixel analysis found the defect behind the "transparent square" complaint: the
  PNG contained a faint ghost SQUARE RING (1,345 pixels, alpha 1–3) hugging the
  canvas edges around the circle; the drop-shadow filter also sat on the rotating
  element, letting the rectangular raster bounds show during rotation.
- home-390: 2,088KB initial — all 4 carousel slides (793KB) + eager below-fold
  FieldMarquee strip (~1.2MB) + 86KB loader PNG.
- home-1440: 1,774KB · home-1920: 5,536KB (incl. 1.5MB hotel master in a 50vw slot)
- services-1440: 1,273KB · svc-land-1440: 2,042KB · svc-snow-390: 2,390KB
- portfolio-1440: 205KB · hww-1440: 1,418KB · industries-1440: 1,076KB · about: 98KB
- Oversized masters: condo-spring-tulip-walk 4288px/4.0MB; hotel set 2400px/1.0–1.7MB;
  hardscape-firepit-lounge-aerial 1.0MB; snow portraits 1600×2133/798KB+430KB;
  many 1448×1086 cards at 430–680KB.

## What changed
1. **Loader**: asset regenerated clean (ghost ring pixels removed, cropped to the
   exact circle bounds) as AVIF 416/640 (10–13KB, was 86KB PNG). Component: rotation
   runs on the img only, img is hard-clipped `rounded-full`, the soft ground shadow
   moved to a STATIC non-rotating circular wrapper — no rectangular canvas, layer
   bounds, or shadow can ever appear during the turn.
2. **Hero carousel**: slides mount their <img> only when visited; slide 2 preloads
   after a 4s idle window (brief: current hero immediate, next after first render,
   rest deferred); carousel behavior/controls untouched.
3. **Below-fold eager removed**: FieldMarquee and logo marquee eager→lazy.
4. **Responsive delivery**: 30+ new AVIF variants (480/640/800/960/1200w) wired via
   srcSet+sizes into DivisionCards, ServiceCards, IndustryCards, PortfolioFeature
   seasons, FeaturedWork mosaic, CapabilityExplorer, StoryRail, FieldMarquee, snow
   story figures, asphalt figures, how-we-work figures — mobile no longer pulls
   desktop-resolution masters; large slots still get full-width files.
5. **Master recompression** (SSIM ≥ 0.97 guard, visually transparent): 15 files,
   ~6.5MB saved — condo 4.0MB→1.2MB (4288→2400w), hotel set ~1.5MB→~1.0MB each,
   hardscape showcase 1.0→0.6MB, card masters ~45% smaller. Frozen hero ladder,
   brand assets, and client logo marks untouched.
6. **sizes attributes** tightened to real rendered widths (33vw→440px etc. against
   the 1440px container cap) so the optimizer stops over-selecting.
