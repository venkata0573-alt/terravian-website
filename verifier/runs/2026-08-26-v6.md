# v6 run — 2026-08-26 — multi-provider lead delivery fix

Objective: "Request a proposal" worked locally but failed on Vercel. Find the
root cause and fix it. Criteria in `verifier/v6/criteria.md`.

## Root cause (confirmed)

FormSubmit's bot protection rejects submissions originating from
hosting-provider / datacenter networks. The proposal route POSTs server-side
from the Vercel function, so on Vercel the request leaves from AWS serverless
egress and FormSubmit refuses it (HTTP 200 with `success:"false"` — caught by
`assertAccepted`, surfaced as the honest failure message). From a residential
or dev-machine IP the same code passes. Identical code, environment-fragile
zero-config transport — no working transport existed on the live deployment.

## Fix

`lib/leadDelivery.ts`: single transport → ordered fallback chain, all plain
HTTPS fetch, no new dependencies, each gated by its env var:

1. `LEAD_WEBHOOK_URL` — generic JSON webhook (Zapier/Make/CRM)
2. `RESEND_API_KEY` — Resend
3. `BREVO_API_KEY` — Brevo (recommended: free 300 emails/day, sender verified
   by email click, no DNS changes needed)
4. `MAILERSEND_API_KEY` — MailerSend
5. `FORMSPREE_ENDPOINT` — Formspree
6. FormSubmit — zero-config last resort (blocked from hosting networks)

`deliverLead` tries each in order and throws only when every transport fails;
the route's honest failure message is unchanged. Per-request timeout reduced
12s → 8s so a full chain of hung providers stays well inside serverless
function limits. `parseFrom()` splits `MAIL_FROM` ("Name <email>" or bare)
for providers that want parts.

## Go-live requirement (handed to user)

FormSubmit cannot work from Vercel, so the live site needs one provider env
var. Recommended: create free Brevo account → verify sender
info@terravianlandscaping.com via email click → API key → set `BREVO_API_KEY`
in Vercel (Production + Preview) → redeploy. Alternatives: `MAILERSEND_API_KEY`
(trial domain, no DNS) or `RESEND_API_KEY` + verified domain + `MAIL_FROM`.
The earlier FormSubmit activation click remains a harmless bonus fallback.
