Trigger: client review — copy sounds robotic, too many words on home,

## Research basis

Surveyed best-in-class landscaping/grounds websites (Wix 15-example roundup,
SiteBuilderReport 41-example set, Dynascape, muffin group). Consistent
winning patterns: photography dominates the homepage, minimal copy,
portfolio and before/after above the fold, CTA always reachable, detail
kept on service/process pages, earthy brand palette with white space. The
redesign follows exactly those patterns.

## Changes

1. **IntroLoader** (new, components/layout/IntroLoader.tsx + globals.css):
   cream overlay, Terravian mark on a sharp-cornered white badge makes one
   slow full turn, tagline settles below, page fades in at ~2.1s. Once per
   session (sessionStorage). Pure CSS animations so no-JS users are never
   trapped; global reduced-motion rule collapses it to an instant pass.
   Verified live: visible on first load, dismissed after ~2.3s, not shown
   again on same-session navigation.
2. **Homepage restructure** (app/page.tsx): 13 sections → 7. Removed from
   home: industry cards, five-stage timeline, maintenance calendar, Snow
   Command stage list, hardscape phase list, outcome cards, testimonial
   placeholders. All that detail already lives (or now lives) on
   /how-we-work (timeline, outcome cards, + calendar moved there),
   /industries, and /services/*. Home is now: hero → division photos →
   field photo rail → portfolio → brand rail → one-breath promise → CTA.
   Home mobile height: 14,874 → 7,553 css px.
3. **Voice pass**: headings and intros rewritten warm/second-person
   ("Lawns, snow, and stone — one phone call." / "The work speaks first" /
   "We show up. That's the whole trick." / CTA "Let's talk about your
   property" — shared CTASection, so all pages warm up). Division card
   lines humanized. No invented claims anywhere.
4. **FieldMarquee images → eager** (same fix class as the logo rail in v5):
   no dark tiles for fast scrollers.
